# 正の行動変容 SIR 模型での最少 jet 階数

論文 **1.0**／証明書一式 **1.0.0** · 公開版の日付 **2026年11月10日** · DOI：未取得。

固定・既知の **k = 2, 3, 5/2** のそれぞれと既知の **N0 > 0** に対し、一時点の感染者数 I(t) と厳密な微分から正の率と状態を識別する最少の jet 階数は、一般的な真の点で **局所4階・大域5階** です。
大域の比較対象は、**同じ k と N0 を持つ全ての正の競合点**です。
正の領域での4階の曖昧さを示す証明書は、模型の識別可能性を調べる研究者が、近傍での識別と正の領域全体での一意性を区別するために使えます。

最初の実行例（Python 3.10 以降で、このディレクトリから実行）：

```sh
python3 -B verify.py
```

期待する出力：`"status": "PASS"` を含む JSON。主定理の代数証明書3件（k=2,3,5/2）を二つの実装で照合し、区間証明書7件を検算します。

## 結果と根拠

4階の jet は I(0), I'(0), ..., I^(4)(0) の5成分、5階は6成分です。「一般的」は正の実領域における真の点の開稠密集合を意味します。

[論文](paper-sir-minimal-jets-v1-en.pdf)に定理と証明、[claims.json](claims.json)に各主張と厳密な根拠の対応があります。補題3と付録Bは、有理被覆上の定数体、最小出力関係、Wronskian による係数の回復、状態の回復を示します。5階上界には[先行研究](#先行研究への謝意)の観測体の定理を用います。この仕事の貢献は、二つの正則な正の点で4階の曖昧さを保証し、三指数についてその上界が最少であると示す証明書です。

N0=10、(alpha,gamma,S0,I0,Z0)=(1,1,2,1,1) では、三指数のそれぞれに同じ J4 を持つ別の正の競合点があります。両点の5次元 jet の Jacobian は非特異です。逆関数定理から、曖昧な真の点の**非空開集合**が得られます。このため J4 では開稠密集合上の大域識別が成立しません。正の人口スケーリングにより、全ての N0>0 に議論が移ります。

k=7/2 と 1+√2 には、別に作られた区間証明書を補足として収めています。alpha=2/3 に初期点を変えた例も含み、同じ4階の曖昧さの仕組みを支持します。

## オフラインで再現する

macOS または Linux の Python 3.10 以降を使います。検査器は Unix の `signal` と `resource` を含む標準ライブラリを使います。Python の assert を有効にして実行してください。

```sh
python3 -B check_packet.py
python3 -B verify.py
```

最初の命令は、ファイルの目録と hash、論文のラベル、主張の範囲のメタデータを照合します。二つ目は一式を一時ディレクトリに写し、次を実行します。

1. 別実装の代数検査器で、固定済みの証明書3件と結果を照合。
2. 保存した有理数区間7件を元の区間式で再検算。
3. 生成側の CAS に依存しない Fraction 検査器で証明書3件を検算。
4. 厳密な保存データから論文の多項式と区間の表を再生成。
5. 三指数の付録Bの関係式・回復係数を Laurent 多項式で検査し、論文に印刷した根の区間を Sturm 法で確認。

二つの代数実装は、元の ODE の jet、正値性、根の分離、両 Jacobian の非零を確かめます。実行時間と最大メモリ量を除く全ての数学的な値を保存結果と比較します。元の一式は保持されます。

既設の Poppler があれば、PDF の本文・メタデータと私有パスのパターンも点検できます。

```sh
python3 -B check_packet.py --pdf
```

三つの命令は全て `"status": "PASS"` を含む JSON を返します。PDF の点検は `"known_private_path_patterns": "PASS"` も返します。再現計算はローカルのファイルを使い、オフラインで行います。

PDF を作り直す場合は、`certificate-tables.tex` を参照できる状態で `paper-sir-minimal-jets-v1-en.tex` を pdfLaTeX で2回処理します。shell escape を無効にし、出力先は一式の外に置きます。ビルドとページの点検記録は [pdf-validation.json](pdf-validation.json) にあります。

## 範囲

主定理は、固定・既知の k∈{2,3,5/2}、既知 N0>0、正の率と状態、一時点の厳密な微分を仮定します。補足の k=7/2 と 1+√2 は主定理の対象を広げません。4階で曖昧な真の点の非空開集合があることは、全ての J4 のファイバーが曖昧であることや、正の点が常にちょうど二つあることを意味しません。全指数・例外点・正のファイバーの分類、未知 k/N0、展開された J5 の逆公式、雑音付きデータの推定、数値安定性は対象外です。

証明支援系での形式化と人間の専門家による査読は未実施です。付録Bの点検は記載した証明と5階への帰着に限り、論文全体の監査ではありません。範囲を区切った文献比較は優先権を証明せず、外部の識別可能性ソフトウェアも実行していません。詳細は検証記録にあります。
